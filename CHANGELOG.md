# Changelog

## v0.1.0 — 2026-10-09

Initial public release for Redmi Watch 4.

- Metallic front-fan illustration, stacked digital time and aligned Turkish date.
- Weather-driven yellow/cyan/white clock colors and 42 weather icon states.
- Airplane steps indicator and rocket battery indicator, without a percent sign.
- Celsius temperature with a negative-sign asset; previous weather dash overlay removed.
- Editable Mi Create project, source assets, build/validation scripts and English/Turkish documentation.

Local project checks and RedmiWatch4 compilation passed. On 2026-10-09, the author confirmed basic operation of the latest revision on the physical Redmi Watch 4, and the pre-release flag was removed. No other device builds are included.
