# Asset provenance

- **Project layout, PNG numeral/mask generation and build scripts:** authored for AeroTurbine by Kadir Yürektürk with AI assistance. MIT license applies to the project's original contributions.
- **Fan illustration:** AI-assisted image generation and editing, developed from a front-view GE9X visual reference supplied during design. The reference photograph is not distributed. The generated high-resolution background is included as `assets/engine-background.png`; the device-sized background is inside the editable project.
- **Outline icons:** [Tabler Icons](https://github.com/tabler/tabler-icons), copyright Paweł Kuna, MIT. Original SVGs and their rendered PNGs are included. Retain `licenses/Tabler-Icons-MIT.txt` when redistributing these assets.
- **Numeral and text bitmaps:** generated from locally installed Arial Bold and Arial Black on Windows. No `.ttf` or `.otf` font files are included; installing or redistributing those fonts is outside this project.
- **Editor and compiler:** external tools. Mi Create and its third-party compiler are not distributed here.

Project licensing does not grant rights to third-party trademarks or imply endorsement. GE9X is mentioned to describe visual inspiration, not product affiliation. No user photographs, phone screenshots, original reference attachments, credentials or device logs are included in the public package.
